1. Architettura Dati e Sicurezza (PHP/PDO)

Per la gestione dei dati ho utilizzato PDO, che permette di separare la logica SQL dai dati dell'utente tramite i Prepared Statements, rendendo il sito immune alla SQL Injection.

// Esempio di inserimento sicuro con Prepared Statement
$sql = "INSERT INTO giochi (titolo, id_genere) VALUES (:t, :g)";
$stmt = $pdo->prepare($sql);
$stmt->execute(['t' => $titolo, 'g' => $genere]);

2. Integrazione API: CheapShark (Cover)

All'apertura della pagina, JavaScript interroga CheapShark per recuperare le immagini. Questo avviene in modo asincrono (senza bloccare il caricamento del sito).

// Recupero dinamico della cover tramite titolo
fetch(`https://www.cheapshark.com/api/1.0/games?title=...`)
    .then(r => r.json())
    .then(data => {
        if(data[0]) cell.innerHTML = `<img src="${data[0].thumb}">`;
    });

3. Dettagli Avanzati: RAWG API

Cliccando sul titolo, viene attivata una seconda API (RAWG) per mostrare i dettagli approfonditi in una finestra modale. Ho implementato una logica per limitare la descrizione ed evitare testi eccessivamente lunghi.

// Pulizia e formattazione della descrizione
let desc = details.description;
if (desc.length > 600) {
    desc = desc.substring(0, 600) + "..."; // Taglio a 600 caratteri
}
document.getElementById('modalDesc').innerHTML = desc;

4. UI/UX e Design Responsive

L'estetica è curata tramite CSS moderno. Ho utilizzato la proprietà object-fit: cover per garantire che le immagini di diversa provenienza si adattino perfettamente alla tabella senza deformarsi.
